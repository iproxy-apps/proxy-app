## Drift notes and rulings (orchestrator, 2026-11-23)

- Verified anchors: `src/app.module.ts:28-33` is the `ThrottlerModule.forRoot({...})` block (two named throttlers, `skipIf` at line 33); `authenticate.controller.ts:21` and `create-account.controller.ts:33` carry `@Throttle({ auth: { limit: 5, ttl: 60_000 } })`; `forgot-password.controller.ts:17-19` and `verify-reset-code.controller.ts:18-20` are `@Post()`/`@HttpCode(200)`/`@UsePipes(...)` with no throttle decorator and no `@nestjs/throttler` import. `test/app/` does not exist yet; create it.
- **Ruling 1 — loop exemption.** The device loop (Maestro on the simulator, `LOOP_TEST_HOOKS=1`, `NODE_ENV=development`) signs in through the UI many times per run from one IP, so a 5/min `/auth/session` limit would break it. The `skipIf` becomes
  `skipIf: () => process.env.NODE_ENV === 'test' || process.env.LOOP_TEST_HOOKS === '1'`.
  `LOOP_TEST_HOOKS` is already a validated env key (`src/env/env.ts`), is guarded to non-production and loopback DB by `TestHooksGuard`, and P5-T10 rejects it in the production schema. Add one e2e case to `test/app/throttle.e2e-spec.ts`, inside the first `describe('rate limiting (e2e)')`, after the `it.each`:
  ```ts
  it('skips throttling entirely when LOOP_TEST_HOOKS=1 (device loop)', async () => {
    process.env.LOOP_TEST_HOOKS = '1'
    try {
      for (let i = 0; i < 6; i++) {
        const response = await request(ctx.app.getHttpServer())
          .post('/auth/session')
          .send({})
        expect(response.status).toBe(400)
      }
    } finally {
      delete process.env.LOOP_TEST_HOOKS
    }
  })
  ```
  The spec therefore ends with **8 tests**, not 7.
- **Ruling 2 — Phase L hooks.** With the `auth` throttler gone, the three test-hook controllers (`src/modules/test-hooks/controllers/{reset,seed-user,mark-account-ready}.controller.ts`) change `@SkipThrottle({ default: true, auth: true })` to bare `@SkipThrottle()`, and `src/modules/test-hooks/test-hooks.throttle.spec.ts:13-16` becomes a single check: test name `'%s skips the default throttler'`, body `expect(Reflect.getMetadata(THROTTLER_SKIP + 'default', controller)).toBe(true)`.
